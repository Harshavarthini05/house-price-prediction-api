# House Price Prediction API

An end-to-end machine-learning regression project that predicts house prices from property details such as bedrooms, bathrooms, living area, location, building year, and property condition.

The project includes exploratory data analysis, preprocessing, feature transformations, comparison of Linear Regression, Random Forest, and Gradient Boosting models, residual analysis, saved model artifacts, and a FastAPI backend for serving predictions.
